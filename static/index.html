🎓 Viva Voce Key Talking Points for Lab Examination

1. Why RandomForest for Placement?

RandomForest handles non-linear interactions (e.g. high CGPA compensating for moderate aptitude), prevents overfitting via bagging, and outputs interpretable feature importances.

2. How is MLOps different from standard DevOps?

DevOps focuses on code and binary deployment (CI/CD). MLOps adds Data Drift, Model Versioning, Continuous Training (CT), and Model Performance Monitoring.

3. What does your CI pipeline verify?

Our GitHub Actions workflow checks code style (Flake8), runs 15 automated Pytest unit tests (data validation, model inferences, HTTP status codes), and builds the Docker image.

4. How do you handle Data Drift?

The system stores baseline training feature statistics (means & standard deviations). During inference, incoming requests are monitored; if Z-shift exceeds 1.25, drift is flagged to trigger retraining.
